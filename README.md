# 🍔 Foodie Spice – Modern Food Ordering Website

**Foodie Spice** is a modern and responsive food ordering website designed to provide users with a smooth and attractive online food browsing experience.
This project focuses on improving and enhancing the User Interface (UI) to make the website visually appealing and easy to use.

## 📌 Project Overview

Foodie Spice allows users to explore delicious food items, view categories, and manage a shopping cart system.
The website includes multiple pages such as Home, Menu, About, and Contact, with a clean layout and improved UI design.

## ✨ Key Features

* 🏠 Home page with hero section and food categories
* 🍕 Menu page with category filter (Pizza, Burgers, Sandwiches)
* 🛒 Shopping cart modal with total price display
* 📄 About page with company information
* 📞 Contact section with details
* 📱 Responsive design for desktop and mobile
* 🎨 Improved and enhanced modern UI

## 🎨 UI Enhancements

* Modern navigation bar design
* Attractive hero section layout
* Better spacing and alignment
* Clean color scheme
* Responsive grid system
* User-friendly interface

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome Icons

food-order-web/

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run **index.html** in your browser
4. Explore the website features

## 🎯 Purpose

This project was developed to practice front-end web development and demonstrate UI design and layout skills for portfolio and learning purposes.

# 🍽️ FlavorHaven — Premium Food Ordering Website

## 📌 Project Description

FlavorHaven is a modern, responsive, and fully interactive **food ordering web application** built using **HTML, CSS, and JavaScript**. It provides a smooth user experience with a beautiful UI, dynamic cart system, and mobile-friendly design.

This project simulates a real-world online food delivery platform where users can browse food items, add them to cart, and manage orders seamlessly.

---

## 🚀 Live Features

✨ Modern UI with glassmorphism design
🍕 Dynamic food menu with images and descriptions
🛒 Fully functional shopping cart (add / remove / quantity update)
💾 LocalStorage cart persistence (data saved in browser)
📱 Fully responsive (mobile, tablet, desktop)
⚡ Smooth animations and transitions
🔔 Toast notifications for user actions
📄 Multi-page navigation (Home, About, Contact, Cart)
👨‍🍳 Clean and professional food card layout

---
